## Personal website for Siddhant Suryakant Jivane

This is a simple, static multi-page site built with HTML and CSS to showcase Siddhant's work as a Pega Lead Consultant and cloud/DevSecOps architect.

### Structure

- `index.html` – Landing page with hero, key highlights, and certifications.
- `about.html` – Profile, working style, and detailed certifications.
- `experience.html` – Timeline of professional experience and education.
- `contact.html` – Contact details and a basic mailto-based contact form.
- `styles.css` – Shared styling, typography, layout, and responsive rules.

### How to run

Because this is a static site, you can:

- Open `index.html` directly in a browser, or
- Serve the folder with any simple HTTP server (e.g. VS Code Live Server, `python -m http.server`, or your preferred static host).

### Deployment

You can host this on:

- GitHub Pages
- Netlify / Vercel
- Azure Static Web Apps
- Any static web hosting provider (including your existing domain).

Just point the host to the root of this folder so that all `.html` files and `styles.css` are available.
